# Project Handoff

This folder groups the short documents a reviewer or paired team needs:

- [One-page spec](./one_page_spec.md) — decision, inputs, outputs, safeguards, and human approval.
- [Test set and results](./test_set_and_results.md) — registered criteria, controlled cases, backtest result, and reproduced failure.
- [Status memo](./status_memo.md) — progress, weaknesses, remaining work, and requests for the team.
- [Source list](./source_list.md) — public data sources and estimate citation gaps.

For setup instructions, start with the project [README](../../README.md) or the beginner walkthrough [`START_HERE.md`](../../START_HERE.md).
